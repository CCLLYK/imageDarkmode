## 三、现有方案与竞品分析

### 3.1 CSS 滤镜方案

```css
@media (prefers-color-scheme: dark) {
  img {
    filter: brightness(0.8) contrast(1.2);
  }
}
```

| 优点 | 缺点 |
|------|------|
| 实现简单，无需额外文件 | 一刀切，所有图片统一处理 |
| 实时生效 | 照片色彩失真，无法区分场景 |
| 无需作者参与 | 无法查看原图（只能刷新） |

**评估**：适用于简单场景，但无法满足"高质量暗黑版"需求。

---

### 3.2 `<picture>` 双版本方案

```html
<picture>
  <source srcset="photo-light.png" media="(prefers-color-scheme: light)">
  <source srcset="photo-dark.png" media="(prefers-color-scheme: dark)">
  <img src="photo-light.png" alt="...">
</picture>
```

| 优点 | 缺点 |
|------|------|
| 作者可提供真正适配的暗黑版 | 作者需要制作两份图片 |
| 效果最佳，信息零丢失 | 创作负担重，覆盖率低 |
| 支持查看原图 | 无自动化工具支持 |

**css-tricks 原文评价**：
> "The downside here is that it requires supplying two files where we only have to deal with one when using CSS."
> （缺点是需要提供两个文件，而使用 CSS 时只需处理一个。）

**评估**：这是**标准方向**，但缺乏"自动生成第二份文件"的工具——这正是你的机会。

### 3.3 Dark Reader 扩展（源码分析）

**获取来源**：npm `darkreader@4.9.134`（通过 unpkg CDN）

**核心机制**：
- 使用 SVG `<feColorMatrix>` 颜色矩阵滤镜包裹图片
- 矩阵由 `createFilterMatrix()` 组合生成：
  - `sepia`（棕褐色调）
  - `grayscale`（灰度）
  - `contrast`（对比度）
  - `brightness`（亮度）
  - `invertNHue()`（反色但保留色相，特定模式）

**代码片段**：
```javascript
function getFilteredImageURL({ dataURL, width, height, useViewBox, src }, theme) {
  const matrix = getSVGFilterMatrixValue(theme);
  const svg = [
    `<svg xmlns="http://www.w3.org/2000/svg" ...>`,
    `<filter id="darkreader-image-filter">`,
    `<feColorMatrix type="matrix" values="${matrix}" />`,
    `</filter>`,
    `<image width="${width}" height="${height}" filter="url(#darkreader-image-filter)" xlink:href="${dataURL}" />`,
    `</svg>`
  ].join("");
  return `data:image/svg+xml;base64,${btoa(svg)}`;
}
```

| 优点 | 缺点 |
|------|------|
| 实时生效，无需预生成 | 一刀切，所有图片统一滤镜 |
| 覆盖所有网页图片 | 照片效果差（反色后色彩怪异） |
| 用户可调整参数 | 无法查看原图（需关闭扩展） |
| 4000万+ 用户验证 | 不生成持久化文件 |

**关键局限**：
1. **无图片分类**：流程图和照片用同一套矩阵
2. **无持久化**：暗黑版仅存在于当前页面渲染中
3. **无作者侧工具**：作者无法生成高质量的暗黑版图片
