## 三、核心功能模块

### 3.1 图片分类器 (`src/classifier.py`)

**功能**：自动识别图片类型（A 类/ B 类）

**算法特征**：
- `white_ratio`: 白色/浅色像素比例
- `unique_colors`: 颜色数量（量化后）
- `edge_density`: 边缘密度（Sobel 梯度）
- `low_saturation_ratio`: 低饱和度像素比例

**分类规则**：
```
A 类（文字/图形）：高白底比例 + 低饱和度 + 高边缘密度 + 颜色少
B 类（照片/绘画）：低白底比例 + 高饱和度 + 低边缘密度 + 颜色多
```

### 3.2 图片处理器 (`src/processor.py`)

**功能**：根据图片类别应用不同的暗黑模式转换策略

#### A 类处理流程：
1. 检测背景像素（RGB > 200）
2. 背景反色：`new_color = 255 - old_color`
3. 前景重映射：保持可读性，调整明度

#### B 类处理流程：
1. RGB → HSV 转换
2. 降亮度：`V = V × 0.7`（medium 强度）
3. 降饱和度：`S = S × 0.6`（medium 强度）
4. HSV → RGB 还原

#### 强度参数：
| 强度 | 亮度系数 | 饱和度系数 |
|------|---------|-----------|
| light（柔和） | 0.85 | 0.8 |
| medium（标准） | 0.7 | 0.6 |
| strong（强力） | 0.5 | 0.4 |

### 3.3 命令行工具 (`src/cli.py`)

**用法**：
```bash
# 单文件处理
python src/cli.py --input <image> --output <image.dark.png>

# 批量处理
python src/cli.py --batch <input_dir> --output-dir <output_dir>

# 指定类型和强度
python src/cli.py --input <image> --type text --intensity strong
```

**参数说明**：
| 参数 | 说明 | 默认值 |
|------|------|--------|
| `--input`, `-i` | 输入图片路径 | 必填 |
| `--output`, `-o` | 输出图片路径 | `<input>.dark.<ext>` |
| `--type`, `-t` | 图片类型：auto/text/photo | auto |
| `--intensity`, `-I` | 变暗强度：light/medium/strong | medium |
| `--batch`, `-b` | 批量处理目录 | - |
| `--output-dir` | 批量处理输出目录 | 当前目录 |

### 9.5 已知遗留问题

1. **A 类色相反转（取舍待定，非已确认缺陷）**：全图 `255 - x` 会同时翻转色相，`samples/002.png` 的绿色语义块因此变成紫色。这是 `docs/算法实现详解.md` §8.1 v2 决策的已知代价——该决策基于浅灰文字的对比度数据，未评估彩色元素；同时与 `docs/需求分析与方案.md` §3.1「彩色元素保持色相」的表述存在冲突。保留现状还是改为保色相，需先做定量评估再定。
2. **`a_class_weight` 是死参数**：v2 起对 A 类无影响，三档强度只作用于 B 类。
3. **GIF 动画只处理第一帧**，WebP 动画未支持。
4. **EXIF 方向未处理**：手机照片可能带旋转元数据，处理时未做 `exif_transpose`。
5. **B 类均匀降饱和会让肤色发灰**，`samples/001.jpg` 可复现。
