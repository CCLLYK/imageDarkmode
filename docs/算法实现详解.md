## 1. 整体流程

处理一张图片生成暗黑版，经历以下三步：

```
输入图片 → 自动分类（A/B） → 对应算法处理 → 输出 .dark.png
```

核心入口在 `src/processor.py` 的 `ImageProcessor.process()` 方法：

```python
def process(
    self, image_path: str, category: str = "auto", output_path: Optional[str] = None
) -> str:
    # 1. 打开图片，并归一化为 RGB / RGBA（兼容灰度、调色板等模式）
    img = _ensure_rgb_mode(Image.open(image_path))

    # 2. 自动分类（如果未指定类别）
    if category == "auto":
        try:
            from .classifier import ImageClassifier
        except ImportError:  # 作为脚本直接运行
            from classifier import ImageClassifier
        classifier = ImageClassifier()
        category, features = classifier.classify(image_path)
        print(f"分类结果: {category} (特征: {features})")

    # 3. 根据类别分别处理
    if category == "A":
        dark_img = self._process_class_a(img)
    else:  # B 类
        dark_img = self._process_class_b(img)

    # 4. 保存输出
    ...
```

## 2. 自动分类（ImageClassifier）

**文件**：`src/classifier.py`

分类器通过提取 5 个视觉特征，用加权评分的方式判断图片属于 A 类还是 B 类。

### 2.1 提取的特征

```python
def _extract_features(self, img_array: np.ndarray) -> dict:
    # 1. white_ratio       —— 白色/浅色像素比例
    white_pixels = np.sum(img_rgb > 200, axis=2) == 3
    white_ratio = np.sum(white_pixels) / total_pixels

    # 2. low_saturation_ratio —— 低饱和度像素比例
    hsv = self._rgb_to_hsv(img_rgb)
    saturation = hsv[:, :, 1]
    low_saturation_ratio = np.sum(saturation < 0.1) / total_pixels

    # 3. unique_colors     —— 估计颜色数量（量化到 512 色空间）
    quantized = np.round(img_rgb / 32).astype(int)
    unique_colors = len(np.unique(quantized.reshape(-1, 3), axis=0))

    # 4. edge_density      —— 边缘密度（梯度法检测）
    edges = self._detect_edges(img_rgb)
    edge_density = np.mean(edges)

    # 5. aspect_ratio      —— 宽高比
    aspect_ratio = width / height
```

### 2.2 评分决策逻辑

```python
def _decide_category(self, features: dict) -> str:
    score_a = 0
    score_b = 0

    # 白底比例高 → A 类 +2，极低 → B 类 +2
    if white_ratio > 0.15:   score_a += 2
    elif white_ratio < 0.1:  score_b += 2

    # 颜色数量少 → A 类 +2，多（>100）→ B 类 +2
    if unique_colors < 50:   score_a += 2
    elif unique_colors > 100: score_b += 2

    # 边缘密度高 → A 类 +1，极低 → B 类 +1
    if edge_density > 0.3:   score_a += 1
    elif edge_density < 0.05: score_b += 1

    # 低饱和度比例高 → A 类 +1，低 → B 类 +1
    if low_saturation_ratio > 0.5: score_a += 1
    elif low_saturation_ratio < 0.2: score_b += 1

    # 平局时按白底比例兜底
    if score_a > score_b:  return 'A'
    elif score_b > score_a: return 'B'
    else: return 'A' if white_ratio > 0.3 else 'B'
```

### 2.3 直觉理解

| 特征 | A 类（流程图/截图）倾向 | B 类（照片/绘画）倾向 |
|------|----------------------|---------------------|
| 白底比例 | 高（文档/白板背景） | 低（自然场景无统一背景） |
| 颜色数量 | 少（色块/线条有限） | 多（连续色调） |
| 边缘密度 | 高（文字/线条轮廓清晰） | 低（自然渐变过渡） |
| 低饱和度 | 高（黑白文字） | 低（彩色照片） |

### 2.4 辅助算法

**RGB → HSV 转换**（用于饱和度计算）：

```python
@staticmethod
def _rgb_to_hsv(rgb: np.ndarray) -> np.ndarray:
    rgb_norm = rgb / 255.0
    r, g, b = rgb_norm[:, :, 0], rgb_norm[:, :, 1], rgb_norm[:, :, 2]
    max_c = np.max(rgb_norm, axis=2)
    min_c = np.min(rgb_norm, axis=2)
    delta = max_c - min_c

    # H 通道（色相）
    h = np.zeros_like(max_c)
    mask = delta > 0
    r_mask = max_c == r
    g_mask = max_c == g
    b_mask = max_c == b
    h[r_mask & mask] = ((g - b) / delta) % 6
    h[g_mask & mask] = 2 + (b - r) / delta
    h[b_mask & mask] = 4 + (r - g) / delta
    h = h / 6.0

    # S 通道（饱和度）
    s = np.zeros_like(max_c)
    s[max_c > 0] = delta[max_c > 0] / max_c[max_c > 0]

    # V 通道（明度）= max_c
    return np.stack([h, s, v], axis=2)
```

**边缘检测**（梯度法，非 Sobel 卷积）：

```python
@staticmethod
def _detect_edges(rgb: np.ndarray) -> np.ndarray:
    gray = np.mean(rgb, axis=2).astype(np.float32)

    # 水平差分（左→右梯度）
    dx = np.abs(np.diff(gray, axis=1))
    dx = np.pad(dx, ((0, 0), (0, 1)), mode='edge')

    # 垂直差分（上→下梯度）
    dy = np.abs(np.diff(gray, axis=0))
    dy = np.pad(dy, ((0, 1), (0, 0)), mode='edge')

    # 平均梯度，归一化到 [0, 1]
    edges = (dx + dy) / 2.0
    return edges / 255.0
```

## 8. 算法演进记录

### 8.1 A 类处理算法变更

#### v1（历史版本，已废弃）：背景/前景分别处理

**实现时间**：项目初始搭建  
**废弃时间**：2026-11-06  
**废弃原因**：实测 `samples/002.png`（白底 + 绿色语义块 + 灰色中英文注释的示意图）时，灰色注释文字经 `x × 0.05 + 30` 处理后亮度降至约 37，与反色后的黑色背景（亮度约 2）对比度过低，阅读困难。

**v1 代码**：
```python
is_background = (r > 200) & (g > 200) & (b > 200)
weight = self._params['a_class_weight']  # medium=0.95
r_dark = np.where(is_background, 255 - r, r * (1 - weight) + 30)
g_dark = np.where(is_background, 255 - g, g * (1 - weight) + 30)
b_dark = np.where(is_background, 255 - b, b * (1 - weight) + 30)
```

**问题根因**：该公式假设"前景是深色文字，需要调暗保留可读性"，但实际场景中风行的「浅灰文字 + 白底」文档中，文字本身亮度就较高（如 156），套用上公式后反而比背景暗不了多少，失去对比度。

#### v2（当前版本，2026-11-06 起生效）：全图统一反色

**思路**：放弃背景/前景区分，所有像素统一执行 `255 - x`。这与主流阅读器/浏览器的暗黑模式做法一致，逻辑简单、效果稳定。

**变更数据**（以 `samples/002.png` 为验证对象）：

| | 背景亮度 | 前景亮度 | 对比度 |
|--|---------|---------|--------|
| 原图 | 253 | 156 | 97 |
| v1 旧算法 | 2 | **37** | 35 ❌ |
| v2 新算法 | 2 | **99** | 97 ✓ |

> **测量范围说明（2026-11-06 补注）**
> 表中的「前景」指灰色注释文字（`element` / `array` / `memory location` 等标签及数字），
> **不包含**图中的绿色语义块。即：本次评估只验证了「文字对比度」这一个维度，
> 彩色元素（绿色块反色后变为紫色）**没有被纳入评估**，这是该决策遗留的盲区。
> 同时需注意，实验对象是一张「白底 + 绿色块 + 灰色文字」的示意图，
> 而非纯文字截图——样本本身就是彩色的，却只测了灰度部分的指标。

**v2 代码**：
```python
def _process_class_a(self, img: Image.Image) -> Image.Image:
    arr = np.array(img)
    if arr.shape[-1] == 4:
        r, g, b, a = arr[:, :, 0], arr[:, :, 1], arr[:, :, 2], arr[:, :, 3]
    else:
        r, g, b = arr[:, :, 0], arr[:, :, 1], arr[:, :, 2]
        a = None
    # 全图反色
    r_dark = 255 - r
    g_dark = 255 - g
    b_dark = 255 - b
    result = np.stack([r_dark, g_dark, b_dark], axis=-1).astype(np.uint8)
    if a is not None:
        result = np.concatenate([result, a[:, :, np.newaxis]], axis=-1)
    return Image.fromarray(result)
```

## 3. A 类处理：精确重着色（v1 历史版本，已迁移至 §8.1）

> **注意**：本节为算法演进记录，当前生产代码已改用全图反色（见 §8.1 v2）。
> 保留本节以便追溯设计思路和历史决策。

**文件**：`src/processor.py`（v1 版本，当前已替换为 §8.1 v2）

### 3.1 核心思想（v1）

A 类图片（流程图、示意图、截图）本质上是"可阅读的内容"——有明确的背景和前景。目标是：

- **背景**：反色（白色→深色）
- **文字/线条/色块**：调整明度但保持色相，使其在深色背景上可读

### 3.2 代码逐行解析（v1）

```python
def _process_class_a(self, img: Image.Image) -> Image.Image:
    arr = np.array(img)

    # ① 分离 RGBA 或 RGB 通道
    if arr.shape[-1] == 4:  # RGBA 含透明度
        r, g, b, a = arr[:, :, 0], arr[:, :, 1], arr[:, :, 2], arr[:, :, 3]
    else:  # RGB
        r, g, b = arr[:, :, 0], arr[:, :, 1], arr[:, :, 2]
        a = None

    # ② 定义"背景像素"：R>200 且 G>200 且 B>200（近白色）
    is_background = (r > 200) & (g > 200) & (b > 200)

    # ③ 获取当前强度的背景反色权重（medium=0.95）
    weight = self._params['a_class_weight']

    # ④ 关键公式 —— 分两类像素分别处理
    #    如果是背景：new = 255 - old（完全反色）
    #    如果是前景：new = old × (1 - weight) + 30（调暗 + 提亮下限）
    r_dark = np.where(is_background, 255 - r, r * (1 - weight) + 30)
    g_dark = np.where(is_background, 255 - g, g * (1 - weight) + 30)
    b_dark = np.where(is_background, 255 - b, b * (1 - weight) + 30)

    # ⑤ 合并通道，恢复透明度
    result = np.stack([r_dark, g_dark, b_dark], axis=-1).astype(np.uint8)
    if a is not None:
        result = np.concatenate([result, a[:, :, np.newaxis]], axis=-1)

    return Image.fromarray(result)
```

### 3.3 公式图解（v1）

```
背景像素（近白色）：
  原值: R=255, G=255, B=255（纯白）
  新值: R=255-255=0,  G=255-255=0,  B=255-255=0 → 纯黑 ✓

  原值: R=240, G=240, B=245（浅灰蓝背景）
  新值: R=15,  G=15,  B=10  → 深蓝黑 ✓

前景像素（文字/线条）：
  原值: R=30,  G=30,  B=30（深灰文字）
  新值: R=30×0.05+30=31.5, G=31.5, B=31.5 → 保持深灰 ✓

  原值: R=0,   G=0,   B=200（蓝色线条）
  新值: R=0×0.05+30=30,  G=30,  B=200×0.05+30=40 → 偏暗的蓝紫色 ✓
```

**公式设计意图**：

| 像素类型 | 变换方式 | 目的 |
|---------|---------|------|
| 近白色背景 | `255 - x` | 完全反色，白→黑 |
| 深色前景 | `x × 0.05 + 30` | 轻微调暗，避免纯黑死板，保持可读性 |

### 3.4 与 B 类的根本区别（v1 视角）

B 类没有明确的"背景/前景"二分，所以无法做反色；A 类因为有白底黑字的特征，可以精确区分两者并分别处理，理论上可以做到"信息零丢失"。

> **注**：v2 改为全图反色后，A/B 类的核心差异主要体现在分类阶段的决策逻辑，而非处理阶段的算法差异。

## 4. B 类处理：色调映射

**文件**：`src/processor.py`，方法 `_process_class_b()`

### 4.1 核心思想

照片和绘画没有"正确"的暗黑答案。策略是：

- **降亮度**：整体变暗，减少刺眼感
- **降饱和度**：鲜艳颜色变得柔和，避免高饱和色在暗黑背景下依然突兀
- **保持色相**：颜色本身不变，只是变暗变淡

### 4.2 代码逐行解析

```python
def _process_class_b(self, img: Image.Image) -> Image.Image:
    # ① 处理透明通道：合成到黑色背景
    if img.mode == 'RGBA':
        background = Image.new('RGB', img.size, (0, 0, 0))
        background.paste(img, mask=img.split()[3])
        img_rgb = np.array(background)
    else:
        img_rgb = np.array(img.convert('RGB'))

    # ② RGB → HSV（OpenCV 实现，性能优于纯 numpy）
    hsv = cv2.cvtColor(img_rgb, cv2.COLOR_RGB2HSV)
    h, s, v = hsv[:, :, 0], hsv[:, :, 1], hsv[:, :, 2]

    # ③ 降亮度：V = V × brightness_factor
    v = v * self._params['b_brightness']  # medium=0.7，即降低 30%

    # ④ 降饱和度：S = S × saturation_factor
    s = s * self._params['b_saturation']  # medium=0.6，即降低 40%

    # ⑤ HSV → RGB 还原
    hsv_dark = np.stack([h, s, v], axis=-1).astype(np.uint8)
    img_dark = cv2.cvtColor(hsv_dark, cv2.COLOR_HSV2RGB)

    return Image.fromarray(img_dark)
```

### 4.3 HSV 颜色空间说明

```
HSV 三通道含义：
┌─────────┬──────────────────┬─────────────────────────────┐
│ 通道    │ 取值范围          │ 物理意义                    │
├─────────┼──────────────────┼─────────────────────────────┤
│ H (Hue) │ 0~179 (OpenCV)   │ 色相：红/绿/蓝等颜色本身     │
│ S (Sat) │ 0~255            │ 饱和度：鲜艳→灰色            │
│ V (Val) │ 0~255            │ 明度：亮→暗                  │
└─────────┴──────────────────┴─────────────────────────────┘

处理只改 S 和 V，H 保持不变 → 颜色不变，只是变暗变淡
```

### 4.4 效果举例

```
原图像素：天空蓝色 (H=210°, S=80%, V=90%)

medium 强度处理后：
  H = 210°  ← 不变
  S = 80% × 0.6 = 48%  ← 饱和度降低，颜色变柔和
  V = 90% × 0.7 = 63%  ← 亮度降低，不再刺眼

→ 深蓝色天空，视觉舒适
```

### 4.5 透明 PNG 的处理

B 类图片常见于 PNG 格式（带透明通道）。直接对 RGBA 做 HSV 转换会有问题，所以先合成到黑色背景：

```python
# 创建一个纯黑画布
background = Image.new('RGB', img.size, (0, 0, 0))
# 把原图按透明度粘贴上去，透明区域显示为黑色
background.paste(img, mask=img.split()[3])
```

这样后续 HSV 处理在纯黑背景上进行，透明区域不会被错误着色。

## 5. 强度档位参数对照

`_get_params()` 方法定义了三个档位的参数：

| 档位 | `a_class_weight` (A类反色强度) | `b_brightness` (B类亮度因子) | `b_saturation` (B类饱和度因子) |
|------|-------------------------------|------------------------------|-------------------------------|
| `light`  | 0.85（弱反色） | 0.85（只降 15% 亮度） | 0.80（只降 20% 饱和度） |
| `medium` | 0.95（标准反色） | 0.70（降 30% 亮度） | 0.60（降 40% 饱和度） |
| `strong` | 1.00（完全反色） | 0.50（降 50% 亮度） | 0.40（降 60% 饱和度） |

**A 类公式中的 weight**（⚠️ 已失效，见下方说明）：
- `weight=1.0`：前景像素 `= x × 0 + 30 = 30`（接近纯黑）
- `weight=0.85`：前景像素 `= x × 0.15 + 30`（保留更多原始色调）

**B 类公式中的 factor**：
- `brightness=0.5`：亮度减半，画面明显变暗
- `brightness=0.85`：亮度只降 15%，变化温和

> ⚠️ **`a_class_weight` 自 v2 起不再生效**。上表第一列只对已废弃的 v1 前景公式有意义；
> 当前 A 类是固定 `255 - x` 的全图反色，**三档强度对 A 类没有任何差别**（只影响 B 类）。
> 该字段暂时保留在 `_get_params()` 中，属于待清理的死参数。
